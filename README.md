# SKYBREAK

A small browser game about movement and destruction: sprint, wall run, slide, swing on a kusarigama, tear down towers and duel with one of five fighters: CHAINBOI, FIREBOI, TANKBOI, LIGHTBOI or SLASHYGAL.

Everything is generated by code with WebGPU. It is a single `index.html` with no libraries or asset files.

## Play

You need a browser with WebGPU, such as a current Chrome or Edge, plus a keyboard and mouse. Open the GitHub Pages site and choose New Game, then a fighter and a rival. Esc pauses. Controls can be changed under Options, Key bindings.

## Run locally

```
node serve.mjs
```

Then open http://localhost:8123.

## Play online

Choose **Multiplayer**, pick a fighter, then one player hosts and shares the room code and the other joins with it. The connection is peer to peer (WebRTC through PeerJS), so turn off VPNs. Players can see each other's IP address, so only play with people you trust.
