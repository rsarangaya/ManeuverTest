# SKYBREAK

A small browser game about movement and destruction: sprint, wall run, slide, swing on a kusarigama, tear down towers and fight a dual-sword rival named CINDER.

Everything is generated by code with WebGPU. It is a single `index.html` with no libraries or asset files.

## Play

You need a browser with WebGPU, such as a current Chrome or Edge, plus a keyboard and mouse. Open the GitHub Pages site and click the game. Press **H** to show or hide the controls.

## Run locally

```
node serve.mjs
```

Then open http://localhost:8123.
